# Linux for Redmi K Pad

This repo contains a series of patches for redmi k pad on mainline linux

## What works

- Camera, Audio and Recording
- Brightness and button
- Touchscreen
- USB0 dual mode (charging/otg)
- USB1 host mode
- WLAN, bluetooth
- GPU (with panthor)
- All cores

## What doesn't

- USB1 mode switch
